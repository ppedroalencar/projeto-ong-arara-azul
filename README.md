# ONG Arara Azul

## Descrição
Website de uma ong fictícia com formulário de cadastro para voluntários

## Objetivos
O website tem por objetivos o estudo de ferramentas como HTML5 e JavaScript de forma prática

## Tecnologias utilizadas
- HTML5
- JavaScript

## Funcionalidades
Formulário para cadastro de voluntários, com validações de dados e máscaras para CPF, telefone e CEP.
